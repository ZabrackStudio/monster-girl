# Música

Pistas que busca el juego (MP3 u Ogg **Vorbis**; Godot no lee Ogg Opus). Todas se repiten en bucle; si falta alguna, ese momento queda en silencio.

| Archivo | Cuándo suena |
|---|---|
| `menu.mp3` | Menú principal y expedientes |
| `intro.mp3` | Informe de la intendente antes de cada asignación |
| `lobby_slime.mp3` | Casa de Reme (y de cualquier chica sin tema propio) |
| `lobby_ratona.mp3` | Casa de Mandy |
| `lobby_dragona.mp3` | Casa de Vipi |
| `lobby_leoparda.mp3` | Casa de Leapy |
| `tienda.mp3` | Tienda y objetos |
| `final_poseida.mp3` | Final Poseída |
| `final_carnal.mp3` | Final Disuelto / Sin aire |
| `final_denuncia.mp3` | Final Denuncia |
| `final_lucha.mp3` | Final Lo intentó y evaluación reprobada |
| `final_marea.mp3` | Final Marea interior / Veta profunda y evaluación aprobada |

Para una chica nueva basta con agregar `lobby_<id>.mp3`.
