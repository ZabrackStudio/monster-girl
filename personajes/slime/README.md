# Arte de Reme (slime)

Coloca aquí los PNG de expresiones y el juego los usará automáticamente
en lugar del dibujo provisional. Nombres esperados en `expresiones/`:

neutral.png · feliz.png · triste.png · cansada.png · inquieta.png · alterada.png · critica.png

Si falta alguno, se dibuja el slime provisional para esa expresión.
